- **著者 / 発行年 / 媒体**: Mark Vainer ほか 2 名 (2026), Electronics
- **ソースURL**: [https://doi.org/10.3390/electronics15163596](https://doi.org/10.3390/electronics15163596)
- **ID**: DOI: 10.3390/electronics15163596
- **理論・アルゴリズムの核心**:
  - 支配方程式・手法: キャッシュ局所性（working set と prefetch の設計）; 並列 reduction（tree 集約）; ヘテロゼネラス計算（CPU/GPU 間の負荷配分）; 負荷分散（work-item 再配分とホットスポット回避）
  - 手法タグ: 並列負荷分散, ヘテロゼネラス計算
  - 抄録に基づく要約: Generating these tables is computationally intensive, and several researchers have proposed utilizing parallel computing to speed up the generation process. In this paper, we bridge this gap by proposing a parallel MPI-based rainbow tables generation method designed for heterogeneous CPU environments. We utilized the static load balancing algorithm using a simple weighting scheme to assign a different number of chains to different processes based on their speeds and capabilities.
- **本3Dシミュレーションへの適用価値**:
  - 非一様な粒子密度に対して空間分割ベースで処理項目を再配分し、GPU カーネルのストールとホットスポットを回避する。
  - CPU/GPU 間の負荷配分を動的に決め、GPU 非搭載環境では CPU へ同一結果でフォールバックする。
