# 風洞シミュレーションにおける境界条件・閉塞度・乱流強度の物理的要件

## 1. 現状の風洞シミュレータが抱える課題
シミュレータにおける「風洞モード」が単に一様な平行流（Wind Vector）を空間に付与して飛行機を定点描画するだけの場合、流体力学的な風洞実験とは呼べない。
以下の流体力学的境界条件と相互作用が欠落している:

1. **風洞胴体（壁面）の境界条件と閉塞効果（Blockage Effect）**:
   壁面が存在することで流路が狭まり、機体周囲の局所流速が加速される効果。
2. **床面境界レイヤー（Ground Boundary Layer）とムービングベルト**:
   地面効果を測定する際、固定床面では空気との間に粘性境界層（低速層）が生じ、実際の飛行（静止大気中を移動）と乖離する。
3. **乱流強度（Turbulence Intensity: $TI$）と整流効果**:
   風洞入口のハニカム・メッシュスクリーンによる整流度と、低レイノルズ数における剥離トリガー。
4. **支持装置（Sting Support）干渉と天秤（Balance）測定**:
   機体を固定するストラットによる空力干渉の補正。

## 2. 流体力学的風洞実験室の物理仕様

### 2.1 閉塞率 (Blockage Ratio) と流速補正
風洞測定部（Test Section）の断面積を $A_{tunnel}$、機体の前方投影面積を $A_{model}$ とする。
- 閉塞率:
  $$\epsilon_b = \frac{A_{model}}{A_{tunnel}}$$
- 一般に $\epsilon_b \le 0.05$（$5\%$ 以下）が推奨される。
- $5\%$ を超える場合、マスケット・アレン（Maskell / Allen）の閉塞補正を適用:
  $$V_{corrected} = V_\infty (1 + \epsilon_{sb} + \epsilon_{wb})$$
  - $\epsilon_{sb}$: 固体閉塞（Solid blockage）
  - $\epsilon_{wb}$: 後流閉塞（Wake blockage, $C_{D0}$ に依存）
  $$q_{corrected} = \frac{1}{2}\rho V_{corrected}^2$$

### 2.2 乱流強度 (Turbulence Intensity)
風洞内の乱れ率 $TI$ は次式で定義される:
$$TI = \frac{\sqrt{\frac{1}{3}(u'^2 + v'^2 + w'^2)}}{V_\infty}$$
- 高精度低レイノルズ数風洞: $TI \le 0.1\% \sim 0.3\%$
- 一般風洞: $TI \approx 0.5\% \sim 1.0\%$
- 紙飛行機の層流境界層剥離は $TI$ に敏感であり、$TI > 1.5\%$ では人工的に層流剥離が抑制されて異常に高い揚力・低い抗力が計測される危険性がある。

### 2.3 ムービングロード（Moving Road）と地面境界
- 地面効果の測定時、風洞床面が静止していると厚さ $\delta(x) \approx 5.0 \frac{x}{\sqrt{Re_x}}$ の境界層が形成され、機体下面の流速が減速して誤った揚力増加/抗力変化を示す。
- 正しい風洞モードでは、床面境界速度 $U_{wall} = V_\infty$（ムービングベルト）または床面境界層吸引（Boundary Layer Suction）を考慮した境界条件モデルを適用する。

## 3. シミュレーション実装への反映指針
1. **測定部幾何モデルの導入**:
   風洞の幅 $W_{tunnel}$、高さ $H_{tunnel}$、長さ $L_{tunnel}$ をパラメータ化。
2. **壁面近接効果と閉塞補正のリアルタイム計算**:
   機体断面積・翼幅と風洞断面比から $V_{local}$ と動圧 $q_{eff}$ を補正。
3. **煙・流線（Streaklines / Streamlines）可視化の物理的厳密化**:
   単なるランダムパーティクルではなく、風洞入口ノズルから注入された粒子が機体前縁渦・翼端渦・後流剥離領域に沿って流体力学的に追従するGPGPUベクトル計算。
4. **天秤計測（6軸ロードセル）の仮想出力**:
   風洞内の拘束力（$F_x$: 抗力, $F_y$: 横力, $F_z$: 揚力, $M_x, M_y, M_z$）をリアルタイムグラフおよび数値で出力。
