# 紙飛行機の縦・横安定性解析と静的余裕（スタティックマージン）

## 1. 概要
紙飛行機の安定飛行は、重心（CG）と空力中心（AC/CP）の相対位置関係、すなわち
「スタティックマージン（Static Margin）」によって支配される。
さらに、二面角（Dihedral）による横安定性と、胴体キール/垂直尾翼による方向安定性が、
旋回・横風・発射時のロール外乱に対する自律復元能力を決定する。

主要参考文献:
- Nelson, R. C. (2014). *Flight Stability and Automatic Control*, 2nd ed. McGraw-Hill.
- Etkin, B. & Reid, L. D. (1996). *Dynamics of Flight: Stability and Control*, 3rd ed. Wiley.
- Anderson, J. D. (2016). *Introduction to Flight*, 8th ed. McGraw-Hill.

## 2. 縦安定性（Longitudinal Stability）

### 2.1 スタティックマージン定義
$$SM = \frac{x_{NP} - x_{CG}}{\bar{c}} \times 100\%$$
- $x_{NP}$: 中立点（Neutral Point）— 迎え角変化に対してピッチングモーメント係数 $C_m$ が不変となる位置。
- $x_{CG}$: 重心位置
- $\bar{c}$: 平均空力翼弦（Mean Aerodynamic Chord）

#### 安定性基準
| SM 値 | 状態 | 飛行挙動 |
|-------|------|---------|
| $SM > 15\%$ | 強い安定 | 頭下げ傾向（ノーズヘビー）。高速直進性は良好だが、滑空距離が短い |
| $5\% \le SM \le 15\%$ | 適度な安定 | **理想領域**。外乱からの自律復元と効率的な滑空を両立 |
| $SM \approx 0\%$ | 中立安定 | 姿勢維持はするが、復元力なし。微小外乱で発散の可能性 |
| $SM < 0\%$ | 不安定 | ピッチアップ発散→ループ・タンブリング。即座に墜落 |

### 2.2 紙飛行機の重心位置と構造的特徴
- **ダーツ型（Classic Dart）**: 先端の多重折りにより $x_{CG}/\bar{c} \approx 20\% \sim 28\%$。$SM \approx 10\% \sim 25\%$。
- **グライダー型（Suzanne 系）**: 前頭部の折り重ねにより $x_{CG}/\bar{c} \approx 25\% \sim 32\%$。$SM \approx 8\% \sim 15\%$。
- **シミュレータ上の課題**: 均一密度の平板としてメッシュを定義すると、幾何学的図心 ≈ 50% MAC に CG が来てしまい、$SM < 0$ → 即ピッチアップ・ループとなる。

### 2.3 ピッチングモーメント特性
トリム状態（$C_m = 0$）を実現するには:
$$C_m = C_{m0} + C_{m\alpha} \alpha + C_{m\delta} \delta_{elevon} = 0$$
- $C_{m0}$: ゼロ揚力ピッチングモーメント（キャンバーやトリムタブ起因）
- $C_{m\alpha} < 0$: 縦安定微分（**負でなければ安定しない**）
  $$C_{m\alpha} = C_{L\alpha} \left(\frac{x_{CG} - x_{AC}}{\bar{c}}\right)$$
- $C_{m\delta}$: エレボン効力微分

## 3. 横・方向安定性（Lateral-Directional Stability）

### 3.1 ロール安定性（二面角効果）
二面角 $\Gamma$ により、横滑りが発生すると下翼側の有効迎え角が増大し、復元ロールモーメントが生じる:
$$C_{l\beta} = -\frac{\partial C_l}{\partial \beta} < 0 \quad (\text{安定条件})$$
- 紙飛行機の典型的な二面角: $\Gamma \approx 3^\circ \sim 12^\circ$
- 二面角が大きすぎるとダッチロール振動が誘起される。
- ダーツ型は胴体キールの深さが実効二面角として機能する。

### 3.2 ヨー安定性（風見鶏効果）
胴体後部のキール/垂直面が横風に対して風見鶏（Weather Vane）効果を発揮:
$$C_{n\beta} = \frac{\partial C_n}{\partial \beta} > 0 \quad (\text{安定条件})$$
- ダーツ型は深いキール胴体そのものが垂直尾翼の役割を果たす。
- グライダー型はキールが浅く、$C_{n\beta}$ が小さいためヨー不安定になりやすい。

### 3.3 横-方向連成（Dutch Roll / Spiral Mode）
低アスペクト比翼では、$C_{l\beta}$ と $C_{n\beta}$ のバランスが崩れるとダッチロール（横方向振動）やスパイラルモード（螺旋降下）が発生する。

## 4. 動的安定性パラメータ（ダンピング微分）

紙飛行機のような低慣性体では、ダンピング効果が飛行品質を決定的に支配する:

| パラメータ | 意味 | 典型値（紙飛行機） |
|-----------|------|-------------------|
| $C_{mq}$ | ピッチダンピング | $-2.0 \sim -8.0$ |
| $C_{lp}$ | ロールダンピング | $-0.3 \sim -0.6$ |
| $C_{nr}$ | ヨーダンピング | $-0.05 \sim -0.2$ |

- $C_{mq}$ が不十分だと、投擲直後のピッチオシレーション（フゴイド/短周期振動）が減衰せず、エネルギーが散逸する。
- **シミュレータ上の課題**: ダンピング微分を省略すると、投擲後に周期的なピッチング振動が永続し、実際の飛行を全く再現できない。

---

## 5. シミュレーションにおける安定性関連の実装要件

1. **CG 位置の正確な算出**: メッシュの幾何学的図心ではなく、折り構造を反映した質量分布からの CG 計算
2. **$C_{m\alpha}$ の明示的計算**: $x_{CG}$, $x_{AC}$, $C_{L\alpha}$ から導出し、符号が負であることを検証
3. **ダンピング微分の実装**: $C_{mq}$, $C_{lp}$, $C_{nr}$ を角速度に比例するモーメントとして組み込み
4. **二面角効果**: 横滑り角 $\beta$ に応じた復元ロールモーメントの計算
5. **トリム解析**: エレボン角 $\delta$ に対するトリム迎え角 $\alpha_{trim}$ と必要揚力の釣り合い計算
6. **スタティックマージン表示**: UI 上で SM を数値・インジケーター表示し、設計パラメータ変更時に即座に安定性を視認可能にする
