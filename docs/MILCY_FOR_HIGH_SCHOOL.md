## 1. プロローグ：紙飛行機は、なぜ飛ぶの？なぜ落ちるの？

### 1.1 誰でも経験したことのある「紙飛行機の失敗あるある」

教室の後ろから先生の方へ向けて、渾身の一投を放った瞬間──
- **「投げた瞬間、地面にグサッと急降下…」** → **機首重すぎ（ノーズダイブ）**
- **「上に急上昇したあと、失速してバタンと墜落…」** → **機首軽すぎ（スタール）**
- **「真っ直ぐ飛ぶかと思ったら、クルクル回って変な方へ…」** → **左右のバランスが悪い（ロール不安定）**

これ、全部**「物理の法則」**で説明できるんだ。逆に言えば、物理がわかれば**「落ちない・曲がらない・遠くまで飛ぶ」**紙飛行機を設計できるってこと！

### 1.2 紙飛行機を操る「4つの力」

飛行機（紙でも本物でも）には、常に4つの力が働いている。

| 力の名前 | 向き | 正体 |
|----------|------|------|
| **重力 (Weight)** | まっすぐ下 | 地球が引っ張る力。質量 × 9.8 m/s² |
| **揚力 (Lift)** | 上向き（翼に垂直） | 空気を下に押し下げる反作用で翼が浮く力 |
| **抗力 (Drag)** | 進行方向と逆 | 空気の抵抗。速いほど、大きいほど強くなる |
| **推力 (Thrust)** | 進行方向 | エンジンの力。紙飛行機の場合は**「投げる力」**だけ！ |

> **高校物理の復習**：作用・反作用の法則（ニュートンの第3法則）そのものだよ。「翼が空気を下に押す → 空気が翼を上に押し返す」＝揚力の正体。

### 1.3 一番大事なのは「重心」と「空力中心」のバランス！

ここが**「紙飛行機設計の核心」**だよ。

- **重心（Center of Gravity：CG）** → 飛行機全体の「重さの中心」。ここを支えれば水平に浮く点。
- **空力中心（Aerodynamic Center：AC）** → 揚力が集中して働く「翼の中心」。だいたい主翼の前から1/4の位置。

```
       揚力 ↑
            │
            │      AC（空力中心）
      翼 ───┼───●────── ここで上向きの力がまとまって働く
            │
            │
            ● CG（重心）
            │
       重力 ↓
```

**なぜ先端を何度も折って重くするの？**

- 重心を**空力中心より前（機首側）**に持ってくるため！
- こうすると、機首が下がろうとするモーメント（回転の力）が生まれる → **自然に機首が下がって、速度が上がって、揚力が増えて、また水平に戻る**という**自己安定**が働くんだ。

> **高校物理「力のモーメント・つりあい」**：力 × 回転中心からの距離。重心と空力中心がズレているからモーメントが生じ、それが「姿勢を戻す力」になる。

### 1.4 「トリム（姿勢の釣り合い）」という魔法

翼の後ろの端（後縁）を**ほんの少し上に曲げる（エレボンを上げる）**だけで、劇的に飛びが変わるのを知ってる？

```
      元の翼           トリム後の翼
      ────────        ────────
            \              \
             \              \  ← 少し上に曲げる（エレボンUP）
              \              \
```

- 後ろが上がると、**尾翼の揚力が下向き**になる → 機首が上がるモーメント発生
- 重心前方のモーメント（機首を下げる力）と釣り合って、**ピッタリ水平滑空**するポイントが見つかる！

これが**「トリム調整」**。職人さんが指先で0.1mm単位で曲げてた世界を、AIが**数学の最適化アルゴリズムで自動でやってくれる**のが milcy のステップ3だ。

## 3. milcyの4つのひらめきステップ（どうやって飛行機を作るの？）

milcy は、**「折り紙で形を作る頭脳」** と **「物理シミュで飛ばす身体」** と **「職人の微調整テクニック」** と **「実戦テスト」** を組み合わせて、最強図鑑を作り上げる。

### ステップ1：MCTS折り紙文法 〜紙を折って新しい形を発明する頭脳〜

#### 人間の折り方を「20工程のルール」に言語化

人間が無意識にやってる折り紙手順を、コンピュータが理解できる**「文法（プログラム言語）」**にした。

```
Step 1: 用紙を中央で山折り（キール＝背骨を作る）
Step 2: 両上角を中央へ谷折り（機首の厚みを作る）
Step 3: さらに折り返して嘴（くちばし）を作る
Step 4: 主翼を水平に谷折り（翼を開く）
Step 5: 翼端を少し山折り（ウイングレット＝安定化）
Step 6: 後縁を少し谷折り（エレボン＝舵を作る）
... 以下、最大20ステップまで継続可能
```

これを**「折り紙ゲノム（設計図）」**として、順序付きの命令列で表現する。

#### モンテカルロ木探索（MCTS）：オセロ・将棋・囲碁のAIと同じ先読み技術！

**「次の折り方をどうすれば、いい飛行機に近づくか？」** を、**将棋のAI（AlphaZeroなど）と同じ「木探索」** で考える。

```
                    ルート（平らな用紙）
                          │
          ┌───────────────┼───────────────┐
          ▼               ▼               ▼
      「半分に折る」  「角を折る」     「翼を開く」  ← 可能な手（折り方）
          │               │               │
      (評価)          (評価)          (評価)  ← シミュレーションで「飛びそう度」を予測
          │               │               │
      ┌───┴───┐       ┌───┴───┐       ┌───┴───┐
      ▼       ▼       ▼       ▼       ▼       ▼
   さらに深く探索...（何万通りもの折り方の木を広げる）
```

- **UCT（Upper Confidence Bound for Trees）公式**で、「有望そうな枝」と「まだ試してない枝」をバランスよく探索
- **40回のシミュレーション（mcts_iterations: 40）** で、その形が「飛びそう」かどうかをざっくり採点
- 優秀な「折り紙プログラム」だけを**初期個体（bootstrap: 8機）**として採用

> **高校情報「木構造・探索アルゴリズム」**：根・枝・葉、深さ優先・幅優先、ヒューリスティック評価関数。まさに授業で習ったアルゴリズムが、最先端AIで動いてる！

### ステップ2：3D MAP-Elites 〜1,000マスの図鑑埋め〜

ステップ1で生まれた「有望な折り紙プログラム」たちを、**本物の物理シミュレーターで飛ばして、1,000マスの図鑑に配置**していく。

#### 6自由度（6DoF）物理シミュレーション：飛行機の動きを完全再現

ただ「前へ進む」だけじゃない。**空間での6つの動き**を全部計算する。

| 並進（位置の変化） | 回転（姿勢の変化） |
|-------------------|-------------------|
| **前後（X軸）** サージ | **ピッチ（機首の上下）** |
| **左右（Y軸）** スウェイ | **ロール（左右の傾き）** |
| **上下（Z軸）** ヘーブ | **ヨー（鼻を左右に振る）** |

これらを **13個の状態変数**（位置3、速度3、姿勢4（クォータニオン）、角速度3）として、**ルンゲ・クッタ法（RK4）という数値積分**で、0.02秒刻みで時間発展させる。

```
時刻 t=0.00s: 投げる瞬間の速度・角度・回転を与える
    ↓ RK4積分（dt=0.02s）
時刻 t=0.02s: 新しい位置・速度・姿勢を計算
    ↓ 空気力計算（揚力・抗力・モーメント）
時刻 t=0.04s: また計算...
    ...
時刻 t=6.00s: 着地 or 墜落 or まだ飛んでる
```

**空気力計算の核心（準定常モデル）：**

- **迎角（α）**：翼と気流の角度 → **揚力係数 CL = CL_α × α**（線形近似）
- **抗力極曲線**：**CD = CD_0 + k × CL²**（誘導抗力込み）
- **ピッチモーメント**：**Cm = Cm_0 + Cm_α × α + Cm_q × (qc/2V)**（動的安定性込み）
- **ロール・ヨーモーメント**も同様に係数モデルで計算

> **高校物理・数学「微分方程式の数値解法・ベクトル・三角関数」**：教科書の「落下運動」や「斜方投射」を、3次元・回転込み・空気抵抗込みでガチで解いてる！

#### MAP-Elites のループ（100回繰り返す）

```
for iteration in 1..100:
    1. 図鑑から「親」をランダムに選ぶ（空いてるマスの隣り優先）
    2. 親の折り紙プログラムを少し変える（突然変異：mutation_rate 0.35）
       - 折り角度を±数度ずらす
       - 山折り⇔谷折りを反転
       - 新しい折りステップを追加/削除
    3. 変異した子を折り紙エンジンで立体化 → 6DoFシミュで飛ばす
    4. 飛行結果から「翼面荷重・静安定余裕・アスペクト比」を計算
    5. 該当するマスの「現在のチャンピオン」より飛距離が良ければ、入れ替える！
```

**途中経過がこんな感じで画面に流れる：**

```

```

> **ニッチ（マス）がどんどん埋まっていく様子、まるで図鑑コンプリートを目指すゲームみたいでワクワクする！**

### ステップ3：Nelder-Mead トリム調整 〜職人のミリ単位の指先微調整〜

図鑑の上位エリート（デフォルト **top-k: 5機**）に対して、**「翼の後ろの角度（エレボン）」と「翼のV字角度（上反角・ダイヘドラル）」を0.1度単位で自動微調整**する。

#### シンプレックス法（Nelder-Mead法）：多面体が坂を転がって谷底を探す

2つのパラメータ（エレボン角、ダイヘドラル角）の組み合わせ空間で、**三角形（2次元ならシンプレックス）**を動かしながら、一番スコアが良い点を探す。

```
        エレボン角
            ↑
            │    ● 悪い点（頂点A）
            │   / \
            │  /   \     シンプレックス（三角形）が
            │ /     \    「反射・拡張・収縮」を繰り返して
            │●-------●   谷底（最適解）へ這い寄る
            │ B       C
            └──────────→ ダイヘドラル角
```

- **反射**：一番悪い頂点を、他の頂点の重心に関して鏡映
- **拡張**：反射先がさらに良ければ、もっとその方向へ
- **収縮**：悪ければ、重心に向かって縮める
- **縮小**：それでもダメなら、三角形全体を最良点に向かって縮める

**制約条件（milcy設定）：**
- エレボン角：-4.0° 〜 +8.0°（上げすぎると失速、下げすぎると機首が下がりすぎ）
- ダイヘドラル角：0.0° 〜 +8.0°（V字にすることでロール安定性アップ）

> **高校数学「多次元関数の最適化・勾配降下法の仲間」**：微分が使えない（シミュレータがブラックボックス）ときに使う、**導関数フリー最適化**の代表格！

### ステップ4：Dryden 乱流テスト 〜扇風機と暴風の実技試験〜

「無風の部屋で飛んだ」だけじゃ、**実戦では通用しない**。milcy は、アメリカ軍の航空機テスト規格 **MIL-F-8785C** に準拠した **Dryden 乱流モデル** を使って、**「どんな風にも負けない真のチャンピオン」**を選ぶ。

#### Dryden 乱流モデル：本物の大気乱流を数式で再現

| 乱流成分 | 物理的意味 | スペクトル（周波数特性） |
|----------|------------|--------------------------|
| **u成分** | 前後方向の風速変動 | 低周波優位（大きな渦） |
| **v成分** | 左右方向の風速変動 | 中周波 |
| **w成分** | 上下方向の風速変動（上昇・下降気流） | 高周波優位（小さな渦） |

これらを**パワースペクトル密度関数**で定義し、**フィルタリングホワイトノイズ**で時系列生成する。

```
          風速
            ↑
    ▲  ▲       ▲           ▲  ▲   ← 突風（ガスト）
   ▐▌ ▐▌      ▐▌          ▐▌ ▐▌
  ▐▐▐▌▐▐▌    ▐▐▌        ▐▐▐▌▐▐▌    ← 乱流（タービュレンス）
 ▐▐▐▐▌▐▐▐▌  ▐▐▐▌      ▐▐▐▐▌▐▐▐▌
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━→ 時間
```

#### 実技試験のメニュー（厳しいよ！）

1. **室内無風（基準）**：2 m/s の穏やかな空気
2. **Dryden 乱流**：上記のリアルな乱流を重ねる
3. **突風（ガスト）**：いきなり 5 m/s の横風がドカン！
4. **投げ方のブレ**：
   - 速度：±0.5 m/s のばらつき
   - 仰角：±2° のばらつき
   - ロール：±3° のばらつき
   - ヨー：±3° のばらつき
5. **ナナメ投げ・上向き投げ**：リリース姿勢をわざとズラす

**各条件で 1〜3 回飛ばして平均スコアを取る。**（モンテカルロ法）

#### 合格ライン

| 指標 | 意味 | 目安 |
|------|------|------|
| **Dryden 生存率** | 乱流で墜落しなかった割合 | **80%以上**欲しい |
| **ロバストネススコア** | 全条件での総合得点 | **0.7以上**なら実用レベル |
| **飛距離スコア** | 無風での飛距離（正規化） | 1.0 に近いほど優秀 |

```bash
git clone https://github.com/your-repo/air_simuration.git
cd air_simuration
```

### 4.3 依存ライブラリをインストール

```bash
pip install -r requirements.txt
```

> **主なライブラリ**：`numpy`（数値計算）、`pyyaml`（設定ファイル読み込み）、`trimesh`（3Dメッシュ扱い）、`scipy`（最適化・統計）

### 4.4 たった1行でAI紙飛行機研究所が起動！

```bash
python -m optimization.cli --iterations 20 --top-k 1 --output-dir output/my_plane
```

**オプションの意味：**
| オプション | 意味 | おすすめ値（最初） |
|------------|------|-------------------|
| `--iterations` | MAP-Elitesの探索回数 | 20（お試し）〜 100（本気） |
| `--top-k` | トリム調整・出力するエリート数 | 1〜5 |
| `--output-dir` | 結果の保存先フォルダ | `output/my_plane` など好きな名前 |
| `--seed` | 乱数シード（同じ結果を再現したい時） | 42（固定） |
