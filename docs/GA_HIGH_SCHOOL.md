## 1. 遺伝的アルゴリズムって何？

### 自然界の進化をマネした最適化手法

**「どんな紙飛行機が一番遠くまで飛ぶかな？」** という問題を解くとき、全ての形を試すのは不可能です（無限にあるから）。そこで、**生物の進化の仕組みを真似て、良さそうなものだけを効率よく探す**のが遺伝的アルゴリズムです。

```
自然界の進化                    遺伝的アルゴリズム
┌─────────────────┐            ┌─────────────────┐
│ 個体（生物）     │    ──►     │ 個体（紙飛行機の設計図） │
│ 遺伝子（DNA）   │    ──►     │ 遺伝子（折り方・投げ方の数値）│
│ 適応度（生存力） │    ──►     │ 適応度（飛距離・滞空時間）   │
│ 選択（生き残る） │    ──►     │ 選択（良い設計を残す）       │
│ 交叉（子供を作る）│    ──►     │ 交叉（設計図を組み合わせる） │
│ 突然変異（変化）  │    ──►     │ 突然変異（少し数値を変える） │
└─────────────────┘            └─────────────────┘
```

### なぜ紙飛行機に向いているの？

- **答えが一つじゃない**: 「遠くへ飛ぶ」か「長く飛ぶか」で最適な形が違う
- **試行錯誤が早い**: コンピューター上で何万回もシミュレーションできる
- **意外な形が見つかる**: 人間が思いつかない折り方を発見できる

## 2. 紙飛行機を「遺伝子」で表す

### 2.1 二種類の遺伝子

紙飛行機の設計図は、**「折り紙プログラム（離散）」** と **「数値パラメータ（連続）」** のハイブリッドです。

```
┌─────────────────────────────────────────────────────────────────┐
│                    1機の紙飛行機の設計図（個体）                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  【離散遺伝子】折り紙プログラム（3〜8ステップ）                  │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ Step 1: 中央で半分に折る（キール＝骨組み）               │   │
│  │ Step 2: 両上角を中央へ折る（機首の厚み）                 │   │
│  │ Step 3: さらに折り返して嘴（くちばし）を作る             │   │
│  │ Step 4: 主翼を水平に折り下げる                          │   │
│  │ Step 5: 翼端を少し折り上げる（ウイングレット）           │   │
│  │ Step 6: 後縁を少し折り曲げる（エレボン＝舵）             │   │
│  └─────────────────────────────────────────────────────────┘   │
│                         │                                       │
│                         ▼ この順序通りに折ると立体になる        │
│                                                                 │
│  【連続遺伝子】9つの数値（CMA-ESが最適化）                       │
│  ┌─────────────────────┬────────┬────────────────────────────┐  │
│  │ 遺伝子名             │ 範囲    │ 意味                        │  │
│  ├─────────────────────┼────────┼────────────────────────────┤  │
│  │ main_wing_fold    │ -180〜180│ 主翼の折り角度（度）        │  │
│  │ elevon_angle      │  -45〜45 │ 後縁トリムの角度（度）      │  │
│  │ cg_offset_x       │ -0.05〜0.05│ 重心の前後位置（メートル）  │  │
│  ├─────────────────────┼────────┼────────────────────────────┤  │
│  │ throw_speed       │   5〜20  │ 投げる速さ（m/s）          │  │
│  │ release_elevation │   0〜45  │ 仰角（度）                 │  │
│  │ pitch_rate        │   0〜8   │ リリース時のピッチ回転      │  │
│  │ roll_deg          │ -45〜45  │ リリース時のロール（傾き）  │  │
│  │ yaw_deg           │ -45〜45  │ リリース時のヨー（向き）    │  │
│  └─────────────────────┴────────┴────────────────────────────┘  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 なぜ「折り紙プログラム」なの？

**「メッシュを伸ばす」のではなく、「本当に折る」から**です。

```
従来のアプローチ          このシミュレーター
┌─────────────┐          ┌─────────────┐
│ 既存の3D    │          │ 平らな用紙  │
│ モデルを    │   VS     │ を実際に    │
│ 拡大縮小    │          │ 折りシミュ  │
└─────────────┘          └─────────────┘
   「形だけ」                「折り目の物理」
```

- 重なり層（機首は6層！）、折り目、厚みまで正しく再現
- この立体から「翼面積」「翼幅」「重心」「慣性モーメント」を自動計算

## 4. 賢く進化させる工夫たち

### 4.1 CMA-ES：継続的に学ぶ「コツ」

普通の遺伝的アルゴリズムだと、良い遺伝子の組み合わせがバラバラになりがち。**CMA-ES（共分散行列適応進化戦略）**は、**「どの遺伝子同士が仲良しか（相関）」を学習しながら探索**します。

```
学習前:                    学習後:
┌─────────────────┐       ┌─────────────────┐
│ 主翼角度: ランダム │       │ 主翼角度: 30°±2度│
│ エレボン: ランダム │  ──►  │ エレボン: 5°±1度│ (主翼と連動！)
│ 重心: ランダム    │       │ 重心: +0.01±0.002│ (主翼と連動！)
└─────────────────┘       └─────────────────┘
   バラバラ探索                連動して効率探索
```

**正規化ユニットボックス [0,1]^9 で探索**し、物理的な範囲にクリップして戻す。

### 4.2 リンケージブロック：壊さない「セット継承」

```
┌────────────────────────────────────────────────────────────┐
│  実機では連動するものは、遺伝子もセットで継承              │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  【main_wing ブロック】← これらは物理的に連動！            │
│    ├─ main_wing_fold_angle_deg  (主翼折り角)              │
│    ├─ elevon_angle_deg          (エレボン角)              │
│    └─ cg_offset_x_m             (重心位置)                │
│                                                            │
│  【throw ブロック】                                        │
│    ├─ throw_speed_mps           (投げる速さ)              │
│    └─ release_elevation_deg     (仰角)                    │
│                                                            │
│  【attitude ブロック】                                     │
│    ├─ pitch_rate_radps          (ピッチ回転)              │
│    ├─ roll_deg                  (ロール傾き)              │
│    └─ yaw_deg                   (ヨー向き)                │
│                                                            │
│  交叉時：ブロックごと「どっちの親からもらうか」コイン投げ │
│  → 相関が壊れない！                                        │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

### 4.3 修復型突然変異：壊れたら直す、壊れてなければ磨く

**「完全ランダムだと75%が把持不合格（持てない）」** なので、毎世代スクラッチから作らない。

```
親（合格済み）                    子（修復型突然変異）
┌─────────────┐                  ┌─────────────┐
│ 折り角度: 30° │  ──ガウス±6°──► │ 折り角度: 27° │  ← わずかにズラす
│ 山折り      │  ──8%で反転──►   │ 山折り      │  ← 時々ひっくり返す
│ 折り目位置  │  ──±0.02ずらす─► │ 折り目位置  │  ← 微調整
└─────────────┘                  └─────────────┘
     合格                              合格のまま進化！
```

**メリット**: 合格個体の「良さ」を保ったまま、周辺を探索できる。

## 5. 複数の「島」で並行進化

### なぜ島を分けるの？

**一つの個体群だけだと「早熟収束（局所最適にハマる）」** リスクがあるから。複数の島で**別々の戦略・乱数**で進化させ、時々エリートを交換する。

```
┌─────────────────────────────────────────────────────────────────┐
│                    4つの島（Island Model）                       │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Island 0          Island 1          Island 2          Island 3 │
│  ┌─────────┐       ┌─────────┐       ┌─────────┐       ┌─────┐ │
│  │ max折=8 │       │ max折=8 │       │ max折=10│       │max折=12│
│  │ 種子=7  │       │ 種子=42 │       │ 種子=123│       │ 種子=99│
│  └────┬────┘       └────┬────┘       └────┬────┘       └──┬───┘ │
│       │                 │                 │               │      │
│       └─────────────────┼─────────────────┼───────────────┘      │
│                         ▼                 ▼                      │
│              ┌─────────────────────────────────────┐            │
│              │     2世代ごとにエリート2機を移住      │            │
│              │  (最悪個体と置換＝新陳代謝)          │            │
│              └─────────────────────────────────────┘            │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 島ごとの違い

| 島 | 最大折りステップ | マイクロフラップ | 役割 |
|----|-----------------|-----------------|------|
| 0  | 8               | 無効            | 基礎探索 |
| 1  | 8               | 無効            | 多様性確保（乱数シード違い） |
| 2  | 10              | 有効            | より複雑な形 |
| 3  | 12              | 有効            | 最複雑・最終段階 |

## 6. 段階的なテストで無駄をなくす

**「いきなり本番の精密シミュレーションだと遅すぎる」** → **安いテストでふるい落とし、有望そうなものだけ精密テスト**

```

    │
    ▼
┌──────────────────────────────────────────────────────────────┐
│ TIER 0: 幾何学フィルタ（把持テスト）                           │

│  チェック: 持てるか？ 重心は手の内か？ 紙が貫通してないか？   │
│  合格率: 約25%（ランダムだと）                                │

└──────────────────────────────────────────────────────────────┘
    │
    ▼
┌──────────────────────────────────────────────────────────────┐
│ TIER 1: 解析的サロゲート（数式だけで瞬間計算）                 │
│  コスト: ~0.5ミリ秒/機                                        │
│  モデル: 揚力傾斜→抗力極曲線→最高滑空比→飛距離推定             │
│  物理: 6-DoFなし、軌道計算なし、閉形式数式のみ                 │

    │
    ▼

│  コスト: ~50ミリ秒/機                                         │
│  モデル: 完全13状態RK4積分、無風                              │

    ▼

│  ブレ: 速度±0.5, 角度±2-3度                                   │

## 7. 自動で戦略を変える「メタ制御」

### 7.1 停滞検出

```
各島ごとにカウンターを持つ:
stagnation_counter = 0

毎世代:
  if 今世代のベスト > 過去ベスト:
      stagnation_counter = 0  # リセット
  else:
      stagnation_counter += 1
      
  if stagnation_counter >= 10:  # 既定値
      → 構造探索シフト発動！
```

### 7.2 決定ジャーナル：全自動決定を記録

```
research_journal.jsonl （1行1JSON、改竄不可）

{"timestamp":"2026-11-12T01:23:45Z","generation":20,"island":2,
 "decision":"structure_search_shift",
 "trigger":"stagnation_detected",
 "changes":{"max_fold_steps":10,"micro_flaps":true}}

{"timestamp":"2026-11-12T01:45:12Z","generation":45,"island":0,
 "decision":"elite_migration",
 "trigger":"migration_interval",
 "changes":{"from_island":2,"elites":2}}
```

**なぜ記録するの？**
- 再現性：同じ条件なら同じ進化ができる
- 監査：なぜその戦略変更したか後からわかる
- デバッグ：失敗した原因を追跡できる

      "max_fold_steps": 10,
      "micro_flaps": true

    ...
  ],

```

**原子的書き込み**（クラッシュしても壊れない）:
```python
# 一時ファイルに書く → fsync → リネームで原子的置換
with open(tmp_path, "w") as f:
    json.dump(state, f)
    f.flush()
    os.fsync(f.fileno())
os.replace(tmp_path, checkpoint_path)
```

| 特徴 | 従来のGA | このシステム |

| 相関学習 | なし | **CMA-ES＋リンケージブロック** |
| 突然変異 | 完全ランダム | **修復型（合格個体を磨く）** |
| 多様性維持 | 単一個体群 | **4島モデル＋エリート移住** |
| 計算効率 | 全個体フル評価 | **4段階フィデリティパイプライン** |
| 自律制御 | 手動調整 | **メタ制御＋決定ジャーナル** |
| 中断・再開 | 困難 | **完全チェックポイント＋ホットマイグレーション** |

## 用語集

| 用語 | 意味 |
|------|------|
| **個体** | 1機の紙飛行機の設計図（ゲノム＋投げ方） |
| **世代** | 進化の1サイクル（親→子供の入れ替え） |
| **適応度** | どれくらい良いかのスコア（飛距離/滞空時間を正規化） |
| **エリート** | その世代で最も適応度が高い個体 |
| **交叉** | 2つの親の設計図を組み合わせて子供を作る |
| **突然変異** | 設計図を少しランダムに変更する |
| **CMA-ES** | 遺伝子の相関を学習しながら効率よく探索するアルゴリズム |
| **フィデリティ** | シミュレーションの精度・忠実度 |
| **把持フィルタ** | 人間の手で持って投げられる形かチェックする |
| **ホールオブフェイム** | 史上最高の個体たちを保存する場所 |
