## 2. 空気の力：揚力と抗力

### 2.1 基本の式（高校物理の復習）

空気の中を物体が動くと、**動圧** という「空気の運動エネルギー密度」が働きます。

$$q = \frac{1}{2} \rho v^2$$

- $\rho$ (ロウ): 空気密度 [kg/m³] （標準状態で約 1.225）
- $v$: 相対風速 [m/s]

この動圧に **面積** と **係数** を掛けて力にします。

| 力 | 式 | 方向 |
|----|-----|------|
| **揚力** (Lift) | $L = q \times S \times C_L$ | 相対風に**垂直・上向き** |
| **抗力** (Drag) | $D = q \times S \times C_D$ | 相対風と**平行・逆向き** |
| **横力** (Side) | $Y = q \times S \times C_Y$ | 相対風に垂直・横向き |

- $S$: 翼面積 [m²]
- $C_L, C_D, C_Y$: **無次元係数**（形状・迎角で決まる）

### 2.2 係数はどうやって決まるの？

**風洞実験のデータ** を式で近似しています。このシミュレーターでは以下のモデルを使います。

#### 揚力傾斜 $C_{L\alpha}$：Helmboldの式（1942年）

三角翼・低アスペクト比翼（紙飛行機みたいな形）専用の式：

$$C_{L\alpha} = \frac{2\pi AR}{2 + \sqrt{AR^2(1+\lambda) + 4AR/\pi}}$$

| 記号 | 意味 | 典型値 |
|------|------|--------|
| $AR$ | アスペクト比 = 翼幅² ÷ 翼面積 | 2.67 (Classic Dart) |
| $\lambda$ | テーパー比 = 先端弦 ÷ 付け根弦 | 0.7 |

**普通の飛行機（AR=8〜10）なら $2\pi \approx 6.28$ だけど、紙飛行機（AR≈3）だと約2.8になる** → **3次元効果で揚力が減る**のを式で表現。

### 2.3 迎角による変化

```
揚力係数 CL
   ^
   │        ● 失速点 (α_stall)
   │       / \
   │      /   \  失速後：Hoerner平板モデル
   │     /     \   CL = 2 sin α cos² α
   │    /       \
   │   /         \
   │  /           \
   │ /             \
   │/_______________\_________> 迎角 α [度]
   0   付着流域     失速   45°
      (線形近似)    領域
```

- **付着流域（α < 失速）**: $C_L \approx C_{L0} + C_{L\alpha} \alpha$ （ほぼ直線）
- **失速後（α > 失速）**: 平板の法線力 $2\sin\alpha\cos^2\alpha$ に滑らかに繋ぐ
- **Polhamus渦揚力**: 鋭い前縁がある三角翼ならさらに揚力アップ（紙飛行機では既定OFF）

## 3. 紙飛行機特有の空力：渦と失速

### 3.1 低レイノルズ数効果（Re = 1000〜100,000）

紙飛行機は**小さく遅い**ので、レイノルズ数 $Re = \rho v c / \mu$ が小さい（$10^3 \sim 10^5$）。

```
レイノルズ数が小さいと起きること:
┌────────────────────────────────────────────────────────────┐
│  1. 層流剥離泡 (LSB: Laminar Separation Bubble)             │
│     ┌─────────────────────┐                                 │
│     │  空気の流れ ──────► │                                 │
│     │  ┌───────────┐      │  剥離した流れが泡のように       │
│     │  │   ╱╲      │      │  留まり、再付着する             │
│     │  │  ╱  ╲     │      │  → 揚力傾斜低下、失速早まる     │
│     │  │ ╱    ╲    │      │  → 抗力増大                     │
│     │  └───────────┘      │                                 │
│     └─────────────────────┘                                 │
│                                                              │
│  2. モデル化（経験式）                                        │
│     x = log₁₀(10⁵/Re)  (Re=10⁵でx=0, Re=10³でx=2)           │
│     CLα倍率    = 1 - 0.04x   (Re=10⁴で -4%)                  │
│     失速角倍率 = 1 - 0.10x   (Re=10⁴で -10%)                 │
│     LSBスケール= 1 + 0.15x   (Re=10⁴で +15%)                 │
│     CD0倍率    = 1 + 0.03x   (Re=10⁴で +3%)                  │
│                                                              │
└────────────────────────────────────────────────────────────┘
```

### 3.2 後縁折り（エレボン）の効果

後縁を少し折り曲げると（$\phi$度）：

$$\Delta C_L = 0.015 \phi, \quad \Delta C_m = -0.012 \phi, \quad \Delta C_D = 0.035 \sin^2\phi$$

- **上に折る（リフレックス）**: 揚力減、機首上げモーメント → 安定性向上
- **下に折る**: 揚力増、機首下げモーメント → 機動性向上

## 4. 6自由度（6-DoF）って何？

### 4.1 6つの自由度

剛体（形が変わらない物体）の動きは **並進3つ + 回転3つ** で決まります。

```
┌─────────────────────────────────────────────────────────────────┐
│                      6 Degrees of Freedom                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   並進（位置の変化）          回転（向きの変化）                  │
│   ┌─────────────────┐        ┌─────────────────┐               │
│   │ X: 前後（前進） │        │ ロール (φ):     │               │
│   │ Y: 左右（横移動）│       │ 右翼が下がる    │               │
│   │ Z: 上下（上昇） │        │                 │               │
│   └─────────────────┘        │ ピッチ (θ):     │               │
│                              │ 機首が上がる    │               │
│   座標系: NED                │                 │               │
│   +X: 北（前）               │ ヨー (ψ):       │               │
│   +Y: 東（右）               │ 機首が右を向く  │               │
│   +Z: 下（重力方向）         └─────────────────┘               │
│                                                                 │
│   高度 = -Z - 地面高さ  （Zが下向き正なのでマイナス）            │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 状態ベクトル（13個の数値）

```python
state = [
    rx, ry, rz,      # 位置 (3)
    vx, vy, vz,      # 速度 (3)
    qw, qx, qy, qz,  # 姿勢四元数 (4)  ← ジンバルロック回避！
    wx, wy, wz       # 角速度 (3)
]
# 合計 13 成分
```

### 4.3 なぜ四元数（クォータニオン）？

オイラー角（ロール・ピッチ・ヨー）だと **ジンバルロック**（ピッチ=±90°でロールとヨーが区別できなくなる）が起きる。四元数なら**特異点なし**で全姿勢を表せる。

```
四元数 q = (w, x, y, z)  ← 4次元の単位ベクトル（ノルム=1）

回転行列への変換:
R(q) = [[1-2(y²+z²), 2(xy-wz), 2(xz+wy)],
        [2(xy+wz), 1-2(x²+z²), 2(yz-wx)],
        [2(xz-wy), 2(yz+wx), 1-2(x²+y²)]]

四元数の時間微分:
dq/dt = 0.5 × q ⊗ [0, ωx, ωy, ωz]  （⊗は四元数積）
```

### 4.4 運動方程式（ニュートン・オイラー）

**並進**: $m \frac{d\mathbf{v}}{dt} = \mathbf{F}_{\text{空力}} + \mathbf{F}_{\text{重力}}$

**回転**: $I \frac{d\boldsymbol{\omega}}{dt} = \mathbf{M} - \boldsymbol{\omega} \times (I \boldsymbol{\omega})$

最後の項 $\boldsymbol{\omega} \times (I \boldsymbol{\omega})$ は **ジャイロ効果**（回転している物体に力を加えると、直角方向に回ろうとする）。コマが倒れないのと同じ原理。

## 5. 紙の強さ：構造応力

### 5.1 翼根曲げモーメント

飛んでいるとき、翼には**揚力**が分布してかかる → 翼根（胴体との境界）に**曲げモーメント**が発生。

$$M_{\text{root}} = \int_0^{b/2} L(y) \cdot y \, dy \approx \frac{1}{2} \rho V^2 S b \cdot C_{M,\text{root}}$$

### 5.2 断面係数（紙を薄い板とみなす）

$$Z = \frac{b \cdot t^2}{6}, \quad t = \frac{\text{坪量 (g/m²)}}{800} \text{ [m]}$$

| 坪量 | 厚み t |
|------|--------|
| 80 g/m² | 0.10 mm |
| 100 g/m² | 0.125 mm |

### 5.3 ビーム理論応力 → 実際の許容応力

ビーム理論（教科書の式）だと：
$$\sigma_{\text{beam}} = \frac{M}{Z}$$

でも**実際の折り紙は箱形・多層**なので、もっと強い。そこで**較正係数**を掛ける：

$$\sigma_{\text{actual}} = \text{KAPPA\_SIGMA} \times \frac{M}{Z}, \quad \text{KAPPA\_SIGMA} = 9.0 \times 10^{-6}$$

**この係数は「ビーム理論値の約1/111,000」** → 実測値に合わせた経験値。

### 5.4 応力指数（0.0 = 安全、1.0 = 破断）

$$\text{stress\_index} = \frac{\sigma_{\text{actual}}}{\sigma_{\text{allow}}}$$

- $\sigma_{\text{allow}}$ = `paper_allowable_stress(坪量, 剛性)` （既定100g/m²で 2.2 kPa）
- **この1つの指標で全経路（6-DoF、GPU、ヒートマップ）共通判定**

### 5.5 上反角の補正

翼がV字（上反角 Λ）だと、揚力の鉛直成分しか曲げモーメントに効かない：

$$K_{\text{dih}} = \cos\Lambda = \frac{1}{\sqrt{1+\tan^2\Lambda}}$$

- 5°なら 0.996（ほぼ1）
- 45°なら 0.707（30%減）

**場計算もスカラー縮約も両方に適用必須**（片方だけだと食い違う）。

## 6. 空気と風：大気モデル

### 6.1 国際標準大気（ISA）

高度 $h$ [m] での標準値：

| 量 | 式 | 海面上値 |
|----|-----|---------|
| 温度 | $T = T_0 - L h$ | $T_0 = 288.15$ K |
| 気圧 | $p = p_0 (T/T_0)^{g/(LR)}$ | $p_0 = 101325$ Pa |
| 密度 | $\rho = p / (R T)$ | $\rho_0 = 1.225$ kg/m³ |

- $L = 0.0065$ K/m（温度減率）
- $g = 9.80665$ m/s²
- $R = 287.058$ J/(kg·K)

### 6.2 サザーランドの式：粘性係数

空気の「ねばけ」= 動粘性係数 $\mu$ は温度で変わる：

$$\mu(T) = \mu_0 \frac{T^{3/2}}{T + S} \frac{T_0 + S}{T_0^{3/2}}$$

- $\mu_0 = 1.716\times10^{-5}$ Pa·s
- $T_0 = 273.15$ K, $S = 110.4$ K

**レイノルズ数** $Re = \rho V c / \mu$ の計算に使う。

### 6.3 3D風場：シミュプレックスノイズ

```
┌─────────────────────────────────────────────────────────────────┐
│                    風場の座標系変換（重要！）                     │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  気象座標系（風の定義）          飛行座標系（シミュレーション）    │
│  ┌─────────────────┐            ┌─────────────────┐             │
│  │ +X: 東          │            │ +X: 北（前進）   │             │
│  │ +Y: 北          │    変換    │ +Y: 東（右）     │             │
│  │ +Z: 上向き      │    ──►     │ +Z: 下向き       │             │
│  └─────────────────┘            └─────────────────┘             │
│                                                                 │
│  風向: 「北から吹く」= 0°           風ベクトル変換:              │
│  (気象庁の定義)                     w_NED = -w_wind            │
│                                                                 │
│  この変換を1箇所(wind_vector関数)で統一！                        │
│  GPUバッチも同じ関数を呼ぶのでズレなし                          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 6.4 風の構成要素

1. **平均風**: 一定の風速・風向
2. **乱流**: 3Dシミュプレックスノイズで空間相関を持たせた揺らぎ
3. **境界層**: 地面近くは風が弱い（対数則・べき乗則）
4. **熱上昇気流**: ガウシアン柱状の上昇風（グライダーが乗るやつ）

## 7. 折り紙の幾何学

### 7.1 「メッシュを変形」じゃなく「本当に折る」

```
従来: 完成形メッシュをスケーリング
      → 層構造・折り目・厚みが分からない

このシミュレーター: 平らな用紙から「折り工程」をシミュレート
      → 本当の立体・層・折り目が分かる
```

### 7.2 折り手順（Classic Dartの例）

```
Step 1: body (キール)
  中央縦線で山折り → V字の骨組み（微小開き3°）

Step 2: corner_l/r (機首第1層)
  両上角を中央へ45°谷折り

Step 3: collar_l/r (嘴・厚い前縁)
  折り返しで機首を鋭く（片側3層、計6層）

Step 4: wing_l/r (主翼)
  胴体残して水平に折り下げ（微小上反角5°）

Step 5: winglet/elevon/trailing (仕上げ)
  翼端折り上げ、後縁トリム
```

**各折り目は「その時の現在位置」を軸に回転** → 物理的な折り順と同じ。

### 7.3 Z-Fighting（重なりチラつき）完全排除

```
紙厚 t = 0.30 mm（実物0.10mmの3倍で見やすく）
空気隙 = 0.12 mm
層ピッチ = 0.42 mm

重なり関係DAGの最長路を層インデックス k とする
任意の重なる2面: k_B ≥ k_A + 1
→ 中間面間隔 ≥ ピッチ > 厚み
→ 絶対に交わらない・同一面にならない（数学的に証明済み）
```

### 7.3 機体アーキタイプ3種類

| キー | 名前 | 特徴 |
|------|------|------|
| `classic_dart` | やり飛行機 | 細長いデルタ、機首鋭い、高速向き |
| `nakamura_lock` | へそ飛行機 | 機首内側折り込み、翼広い、安定 |
| `sky_king` | スカイキング | 鈍頭ノーズ、ウイングレット、滞空向き |

## 8. GPUで高速計算

### 8.1 なぜGPU？ → 同じ計算を大量に並列実行

遺伝的アルゴリズムでは **1世代で数万機** を評価。CPUで順番にやると遅すぎる。

```
CPU（直列）                    GPU（並列）
┌─────────────┐               ┌────────────────────────┐
│ 機体1 計算  │               │ 核心×数千で同時実行      │
│ 機体2 計算  │     VS        │ ┌──┬──┬──┬──┬──┐       │
│ 機体3 計算  │               │ │機│機│機│機│...│       │
│ ...         │               │ │体│体│体│体│   │       │
│ 機体10000   │               │ └──┴──┴──┴──┴──┘       │
└─────────────┘               └────────────────────────┘
  10000 × 50ms = 500秒          10000 ÷ 3000 × 50ms ≈ 0.17秒
  (8分)                          (3000倍高速！)
```

### 8.2 3つの実行モード

| モード | 用途 | 物理モデル | 精度 |
|--------|------|------------|------|
| **6-DoF正規** | 基準・検証 | 13状態RK4、全物理 | ★★★★★ |
| **GPUバッチ** | 大量評価 | **正規と同一13状態RK4**をベクトル化 | ★★★★★ |
| **GPUアンサンブル** | 不確実性 | 3-DoF点質量、陽的Euler | ★★★☆☆ |
| **解析サロゲート** | 高速スクリーニング | 閉形式滑翔解 | ★★☆☆☆ |

**重要**: GPUバッチは**手抜きじゃない**。正規経路と**全く同じ物理モデル**をGPUで並列化しただけ。

### 8.3 CUDA Graph Capture でさらに高速

```
通常のGPU実行:              CUDA Graph Capture後:
┌─────────────────┐         ┌─────────────────┐
│ カーネル起動     │         │ グラフとして    │
│ → 計算          │   ×40   │ 一括記録        │
│ カーネル起動     │   回    │ ↓               │
│ → 計算          │         │ 1回リプレイで   │
│ ...             │         │ 全ステップ実行   │
└─────────────────┘         └─────────────────┘
  起動オーバーヘッド大          起動オーバーヘッドほぼゼロ
  (1ステップ40カーネル)         (約80倍高速！)
```

## 9. 数値計算の工夫

### 9.1 RK4法（4次ルンゲ・クッタ）

微分方程式 $\frac{dx}{dt} = f(t, x)$ を高精度に解く：

```
k1 = f(t, x)
k2 = f(t + h/2, x + h·k1/2)
k3 = f(t + h/2, x + h·k2/2)
k4 = f(t + h, x + h·k3)

x_next = x + h/6 × (k1 + 2k2 + 2k3 + k4)
```

**4次の精度**: ステップ幅 $h$ を半分にすると誤差は $1/16$ に！

### 9.2 適応ステップサイズ（自動で刻み幅調整）

```
もし変化が激しければ → ステップを小さく（細かく計算）
もし穏やかなら      → ステップを大きく（高速化）

判定基準:
- 角速度変化 > 2.0 rad/s     → 半分にする
- 速度変化 > 25 m/s          → 半分にする
- 姿勢変化 > 0.35 rad (20°)  → 半分にする
- 予測より大きくジャンプ     → 半分にする

最大6回リトライ → だめなら「発散」判定
```

## まとめ：このシミュレーターの物理の特徴

| 領域 | 採用モデル | なぜそれを使うか |
|------|-----------|-----------------|
| 揚力傾斜 | Helmbold (1942) | 低AR翼（紙飛行機）専用式 |
| 失速後 | Hoerner平板 (1965) | 係数不要・形状のみで決まる |
| 低Re効果 | LSB経験式 | 紙飛行機のRe領域に合わせて調整 |

| 構造応力 | ビーム理論 + 較正係数 | 実測に合わせた経験的補正 |
| 大気 | ISA + Sutherland | 国際標準・温度依存粘性 |
| 風 | Simplex Noise + 境界層 | 空間相関のあるリアルな乱流 |
| 折り紙幾何 | プロシージャル折りシミュ | 本当の層構造・折り目再現 |
| GPU並列 | CUDA Graph Capture | 起動オーバーヘッド排除で超高速 |

## 用語集

| 用語 | 意味 |
|------|------|
| **迎角 (Angle of Attack, α)** | 機体の向きと相対風の角度 |
| **失速 (Stall)** | 迎角が大きすぎて揚力が急激に落ちる現象 |
| **レイノルズ数 (Re)** | 慣性力/粘性力の比。大きい=乱流、小さい=層流 |
| **アスペクト比 (AR)** | 翼幅² ÷ 翼面積。大きい=細長い翼 |
| **四元数 (Quaternion)** | 4次元ベクトルで回転を表す（ジンバルロックなし） |
| **RK4** | 4次の精度を持つ数値積分法 |
| **動圧 (Dynamic Pressure)** | ½ρv²。空気の運動エネルギー密度 |
| **誘導抗力 (Induced Drag)** | 揚力を生む副産物として発生する抗力 |
| **地面効果 (Ground Effect)** | 地面近くで誘導抗力が減り揚力が増す現象 |
| **モンテカルロ法** | 乱数で何回も試して統計を取る方法 |
