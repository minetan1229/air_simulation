# トラブルシューティング & FAQ (Troubleshooting)

本ドキュメントでは、環境構築、起動時、およびシミュレーション実行時によくある問題と対処法をまとめています。

---

## 1. 起動・環境に関する問題

### Q1: `ModuleNotFoundError` が発生して起動できない
- **原因**: 仮想環境が有効化されていない、または依存パッケージのインストールが不完全です。
- **対処法**:
  ```powershell
  # 仮想環境の有効化を確認
  .\.venv\Scripts\Activate.ps1
  # 依存関係を再インストール
  pip install -r requirements.txt
  ```

### Q2: GPU (CUDA / CuPy) が認識されない
- **原因**: インストールされている CUDA バージョンと CuPy / PyTorch のバージョンが一致していない可能性があります。
- **対処法**:
  本シミュレーターは GPU が利用できない場合でも **自動的に NumPy による CPU 演算へフォールバック** します（動作上エラーにはなりません）。GPU 加速を有効化したい場合は、CUDA ツールキットのバージョンを確認の上、適切なパッケージ（例: `cupy-cuda12x`）を導入してください。

## 2. 3D描画・UIに関する問題

### Q1: 3Dビューアが真っ黒または描画されない
- **原因**: ブラウザのハードウェアアクセラレーションが無効になっているか、WebGL 2.0 がサポートされていない可能性があります。
- **対処法**:
  1. Google Chrome や Microsoft Edge などの最新ブラウザをご利用ください。
  2. ブラウザ設定で「グラフィックアクセラレーション（ハードウェアアクセラレーション）を使用する」が有効になっているか確認してください。
  3. `chrome://gpu` または `edge://gpu` を開いて WebGL 2.0 の状態を確認してください。

### Q2: 3Dモデル（STL / OBJ / GLB）のインポートが失敗する
- **原因**:
  - ファイルサイズが Flask の上限（64MB）を超えている。
  - ポリゴンメッシュが破損している、または法線ベクトルが極端に乱れている。
- **対処法**:
  - 3Dモデルファイルサイズが 64MB 以内であることを確認してください。
  - Blender や MeshLab 等でメッシュの非多様体ジオメトリ（Non-manifold）を修復してから再度アップロードしてください。

## 3. シミュレーション・最適化に関する問題

### Q1: 飛行軌跡が不自然に急停止・急激に跳ね上がる
- **原因**:
  極端な投擲初速（音速超え）や過大な初期迎角が設定された場合、適応サブステッピングが極限まで細分化され、タイムステップが微小になるか着地判定に達している可能性があります。
- **対処法**:
  初速（通常 $3 \sim 15\text{ m/s}$ 程度）や投擲角度（$0^\circ \sim 20^\circ$ 程度）を現実的な範囲に設定してください。

### Q2: 最適化ジョブ (NSGA-II) の完了までに時間がかかる
- **原因**:
  個体数（Population）や世代数（Generations）を大きく設定しすぎている場合、評価フライト回数が増加します。
- **対処法**:
  - まずは「Nelder-Mead」などの局所探索アルゴリズム、または小さな個体数（12〜24程度）でテスト実行してください。
  - 推定完了時刻（ETA）と残り時間表示を確認しながらジョブを調整してください。
