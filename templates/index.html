⚠️ 3D描画 (RENDER) で Intel 内蔵GPUが使われている場合について:

Windows ノートPCでは、バッテリー節約のため Web ブラウザ（Chrome / Edge 等）が自動的に内蔵GPU (Intel) に割り当てられる仕様になっています。
10万粒子風流線や高精度シェーダーを NVIDIA GeForce RTX 4060 で描画させるには、以下のいずれかの方法でブラウザを高パフォーマンスGPUに設定してください。

🚀 最短方法: PowerShell コマンドで一発設定（再起動後反映）

PowerShell を管理者権限不要で開き、以下のコマンドを貼り付けて実行すると、Windows のグラフィック設定に Chrome / Edge の高パフォーマンス（RTX 4060）設定が即時登録されます。

New-Item -Path "HKCU:\Software\Microsoft\DirectX\UserGpuPreferences" -Force | Out-Null; Set-ItemProperty -Path "HKCU:\Software\Microsoft\DirectX\UserGpuPreferences" -Name "C:\Program Files\Google\Chrome\Application\chrome.exe" -Value "GpuPreference=2;"; Set-ItemProperty -Path "HKCU:\Software\Microsoft\DirectX\UserGpuPreferences" -Name "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" -Value "GpuPreference=2;"

※実行後、ブラウザを完全に閉じて再起動すると RTX 4060 で WebGL が動作します。

🛠️ 手動方法①: Windows の設定画面から設定
  1. Windows の「設定」(Win + I) を開く
  2. 「システム」→「ディスプレイ」→「グラフィック」を開く
  3. アプリ一覧から使用中のブラウザ（Google Chrome または Microsoft Edge）をクリック
  4. 「オプション」ボタンを押し、「高パフォーマンス (NVIDIA GeForce RTX 4060)」を選択して「保存」
  5. ブラウザを再起動
⚙️ 手動方法②: NVIDIA コントロールパネルから設定
  1. デスクトップの何もない場所を右クリックし、「NVIDIA コントロールパネル」を開く
  2. 左メニューの「3D 設定の管理」を選択し、「プログラム設定」タブを開く
  3. 「1. カスタマイズするプログラムを選択する」で使用ブラウザを選択
  4. 「2. このプログラム用の優先するグラフィックスプロセッサを選択する」で「高パフォーマンス NVIDIA プロセッサ」を選択して「適用」
  5. ブラウザを再起動
