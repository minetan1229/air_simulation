⚠️ なぜ 3D描画 (RENDER) だけ Intel 内蔵GPUになるのか？

Windows ノートPC (Optimus) では、バッテリー節約のためブラウザの WebGL 描画に自動で Intel 内蔵GPU が割り当てられます。
さらに、Chrome がバックグラウンドで起動しっぱなしになっている場合、Windows の設定変更後も古い GPU プロセスが居座り続けるため、Intel のままになってしまいます。

👉 上記の「RTX 4060 強制モードで開く」ボタンを押すか、プロジェクト内の launch_gpu_render.bat を実行すると、確実に RTX 4060 で描画されます。

🚀 最短解決: launch_gpu_render.bat または PowerShell コマンド

プロジェクト直下の launch_gpu_render.bat をダブルクリックするか、PowerShell に以下を貼り付けて実行すると、古い常駐プロセスをリフレッシュして RTX 4060 強制フラグ付きで起動します。

New-Item -Path "HKCU:\Software\Microsoft\DirectX\UserGpuPreferences" -Force | Out-Null; Set-ItemProperty -Path "HKCU:\Software\Microsoft\DirectX\UserGpuPreferences" -Name "C:\Program Files\Google\Chrome\Application\chrome.exe" -Value "GpuPreference=2;AutoHDREnable=0;"; Set-ItemProperty -Path "HKCU:\Software\Microsoft\DirectX\UserGpuPreferences" -Name "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" -Value "GpuPreference=2;AutoHDREnable=0;"

※実行後、ブラウザのバックグラウンド常駐プロセスを終了して再起動すると RTX 4060 が即時適用されます。

🛠️ 手動方法①: Windows の設定画面から設定
  1. Windows の「設定」(Win + I) を開く
  2. 「システム」→「ディスプレイ」→「グラフィック」を開く
  3. アプリ一覧から使用中のブラウザ（Google Chrome または Microsoft Edge）をクリック
  4. 「オプション」ボタンを押し、「高パフォーマンス (NVIDIA GeForce RTX 4060)」を選択して「保存」
  5. ブラウザを再起動
⚙️ 手動方法②: NVIDIA コントロールパネルから設定
  1. デスクトップの何もない場所を右クリックし、「NVIDIA コントロールパネル」を開く
  2. 左メニューの「3D 設定の管理」を選択し、「プログラム設定」タブを開く
  3. 「1. カスタマイズするプログラムを選択する」で使用ブラウザを選択
  4. 「2. このプログラム用の優先するグラフィックスプロセッサを選択する」で「高パフォーマンス NVIDIA プロセッサ」を選択して「適用」
  5. ブラウザを再起動
