# 物理修正の実装・検証記録

更新日: 2026-10-10。ロードマップ: [PHYSICS_REPAIR_PLAN.md](PHYSICS_REPAIR_PLAN.md)。

基礎式と投擲モードを修正した。P1の完了条件「手元から上昇後、自然に移行して25秒以上滑空」は未達であり、全計画の完了とは扱わない。

## 実装した変更

| 領域 | 変更・検証 |
|---|---|
| 慣性 | 台形翼の解析的慣性、対称テンソルと積慣性、正定値・三角不等式の検査。平板解析解と軸変換を検証 |
| メッシュ | 主慣性値の並べ替えを機体軸へ割り当てる処理を廃止。開いた面の面積積分で慣性を算出 |
| 空力 | 局所密度・粘性を動圧とReへ反映。連続した失速後の剥離抗力を追加。低迎角・大迎角・負迎角を検証 |
| 力の座標 | ねじれによる係数補正と相対風による力の向きを分離。横滑りを含む揚力の直交・抗力の非正の仕事を検証 |
| ピッチ | 重力・水平基準の人工姿勢復元を除去。ピッチ減衰の重複係数を修正 |
| しなり | 動圧と紙剛性から後縁折り角を変化させ、揚力・モーメントに共通に反映 |
| 応力 | 荷重を `m*g*nz` で評価し動圧の二重計上を除去。断面係数・翼根曲げの単位と分割依存を修正。梁解析解と速度2倍で荷重4倍を検証 |
| 積分・履歴 | 再試行で半分にした刻みの実時間を集計。リセット後の発射フレームを記録 |
| プリセット | `full_flight` / `apex_glide` を明示。新UIは手元投擲が既定。旧リクエストは互換経路。非対応モード拒否・保存復元を検証 |
| 評価・ログ | 合計・頂点後・連続滑空を別集計。ログにモードとモデル版を追加。CSV往復・旧ログの既定値を検証 |
| UI | モード表示、軌道境界からのカメラ調整、記録に沿ったシーク・逆送り、未達結果の明示 |
| 最適化 | GPU近似・サロゲート・実6DoFのモデル種別と検証資格を結果とPareto候補へ付与。混在を明示 |

後縁変形の上限8度・圧力スケール、剥離抗力、紙の材料係数は経験モデル。実機測定による校正、履歴依存の変形・フラッターは未検証。

## 性能検証

基準はUnite、無風、26 m/s、78度、高さ1.8 m。修正前の `artifacts/physics_repair/baseline.json` を保持した。以前の31.17秒は人工姿勢復元を含むため、物理的な性能の証拠には使用しない。

修正後の固定刻み0.005秒: 最高高度約10.42 m、飛行時間約1.755秒、連続安定滑空0秒。15〜17 m・25秒以上の滑空・合計30秒超は未達。指定範囲の初速・角度・高さを組み合わせた18条件でも未達。

固定刻み0.01→0.005秒の差は高度約0.47%、飛行時間約0.86%。0.02秒には再試行があり、3刻み全体の収束は不合格。適応刻みでも細かい2条件の飛行時間差約1.44%で、1%の基準を満たさない。頂点開始の長い飛行は、手元からの成功には数えない。

軌跡、力・モーメント、エネルギー、初期条件、しきい値、ソースハッシュ、失敗を含む結果: [検証レポート](artifacts/physics_repair/verification.md)、`after.json`、`summary.csv`。再現: `python tools/verify_physics_repair.py --sweep`。

## 残る修正（優先順）

1. 大迎角・逆流・低速のピッチモーメントと後縁変形を、実測または根拠のあるモデルで校正する。性能合わせの人工トルクや頂点での状態差し替えは行わない。
2. 接地処理・積分の受理条件を切り分け、再試行を含む時間刻み収束と飛行終了時刻の精度を改善する。
3. 上昇から滑空への連続移行を実証してから、各プリセットのフルフライト校正を確定する。現行レシピは `performance_validated=False`。
4. GPU近似と実6DoFで目的関数が混在する最適化経路を統一する。現在は混在を明示した段階でモデル間一致は保証していない。
5. 通常ログに設定・校正根拠・区間指標をまとめたエクスポートを整備する。現在はログにモードと版、設定出力に初期条件、APIと検証成果物に区間指標があり、単一出力には未統合。
